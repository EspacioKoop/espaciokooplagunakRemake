# Paridad funcional con el original

Referencia: EspacioKoop/espaciokooplagunak, commit `fecd0740545f485d2402c6dfe4b47d5a859cb96c`.

**Criterio de cierre: todas las características existentes, reimplementadas con código y recursos propios, accesibles desde el ejecutable autónomo. Foundry es un adaptador opcional.**

La auditoría por funciones está en curso. El inventario de archivos no equivale a revisión semántica de todo el código. Las pruebas de las seis misiones no demuestran paridad con el original.
